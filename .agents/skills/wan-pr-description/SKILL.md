# wan PR Description

Write the pull request body with exactly these four level-two sections, in this order:

## Motivation

Explain the problem or project goal. Do not repeat the title.

## Changes

List the implementation changes and identify each included task when the PR contains a task group.

## Testing

List only checks that were actually run and their results. Include known warnings or limitations.

## AI Usage

State how Claude Code was used and whether the implementation stayed within the task and design scope.

Keep the body concise. Use English, link the relevant task IDs, and do not add sections before, between, or after these four sections.
