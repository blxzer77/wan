## M4-01 Routines：表、cron 与一次性 routine

- **状态**：todo
- **依赖**：M1-08、M2-05
- **设计依据**：[设计 5.2](../design/architecture.md#s5-2)
- **范围**：表 routines / inbox_events（dedup_key 唯一）/ routine_runs；cron 也是事件源；插入 run 与推进 next_fire 同事务；routine = 触发过滤器 + 提示词，归属单个 bot，命中事件作为不打断输入入队；带日期的一次性 routine；定时至少间隔 5 分钟；每 bot 最多 50 个；每 routine 保留最近 20 条运行记录；IANA 时区与夏令时；单调时钟、时钟跳变重算；重叠策略默认 skip / buffer_one；弹性窗口确定性抖动；routine 30 分钟超时。
- **验收标准**：
  - fake clock 测试：DST、时钟跳变、限额 50 / 20 / 5 分钟
- **涉及文件 / crate**：crates/wan-core/src/routines/**
